ΑΛΛΑΓΕΣ SITE ΣΑΕΚ

Περιλαμβάνονται μόνο οι σελίδες και τα κοινά αρχεία που άλλαξαν. Αντιγράψτε τα στη ρίζα του site διατηρώντας τις διαδρομές τους.

Σε κάθε σελίδα υπάρχει πλέον το ίδιο κουμπί «← Πίσω». Επιστρέφει στην προηγούμενη σελίδα του site όταν υπάρχει σχετικό ιστορικό περιήγησης. Αν η σελίδα ανοίξει απευθείας, οδηγεί στο γονικό μάθημα ή την ενότητα. Τα προηγούμενα κουμπιά επιστροφής που διπλασίαζαν τη λειτουργία κρύβονται. Στην αρχική σελίδα το κουμπί απενεργοποιείται όταν δεν υπάρχει προηγούμενη σελίδα.

Περιλαμβάνεται επίσης η προηγούμενη διόρθωση των διακοσμητικών σημάτων ΣΑΕΚ. Τα τεχνικά σύμβολα και οι λυχνίες διατηρήθηκαν.
