ΔΙΟΡΘΩΜΕΝΑ ΑΡΧΕΙΑ SITE ΣΑΕΚ

Το ZIP περιέχει μόνο τις 35 σελίδες και τα κοινά αρχεία που χρειάζονται για τις διορθώσεις. Αντιγράψτε τα στη ρίζα του site διατηρώντας τις διαδρομές.

Διορθώσεις: η αρχική δεν εμφανίζει κουμπί «Πίσω»· τα Εργαστήρια 4 και 5 έχουν κανονικό κουμπί επάνω δεξιά· οι άλλες σελίδες έχουν το κοινό κουμπί επιστροφής. Οι αναφορές των κοινών αρχείων αναβαθμίστηκαν σε v=2 ώστε να φορτωθεί η νέα έκδοση. Περιλαμβάνονται και οι προηγούμενες αφαιρέσεις διακοσμητικών συμβόλων.
