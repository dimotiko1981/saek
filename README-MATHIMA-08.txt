ΣΑΕΚ — ΜΑΘΗΜΑ 8: MOST, FlexRay και Automotive Ethernet
==========================================================

Το θέμα αντιστοιχεί στο μάθημα 9 της «Τελικής Κατανομής» του χρήστη,
αλλά καταχωρίστηκε ως Μάθημα 8 στον ιστότοπο, χωρίς αναρίθμηση προηγούμενων μαθημάτων.

ΠΕΡΙΕΧΟΜΕΝΑ
- mathima-08.html : 30 διαφάνειες, τεστ αυτοαξιολόγησης 30 ερωτήσεων (τυχαία σειρά επιλογών)
- downloads/Mathima_08_MOST_FlexRay_Automotive_Ethernet.pdf : PDF 30 διαφανειών
- ergastirio-mathima-08.html : είσοδος στο εργαστήριο
- ergastirio-mathima-08-protocols.html : 12 σενάρια επιλογής πρωτοκόλλου
- ergastirio-mathima-08-topologies.html : 8 ασκήσεις αναγνώρισης τοπολογιών
- ergastirio-mathima-08-flexray.html : 6 αποστολές στατικών slots FlexRay
- ergastirio-mathima-08-diagnosis.html : 25 υποθετικά περιστατικά με 100 ερωτήσεις
- assets/js/mathima-08-quiz.js και mathima-08-lab.js : λειτουργικότητα
- assets/css/mathima-08-lab.css : εμφάνιση εργαστηρίου
- assets/slides/mathima-08/slide-01.webp έως slide-30.webp : διαφάνειες
- index.html : μόνο η νέα κάρτα Μαθήματος 8 (έχει τοποθετηθεί στη ρίζα)

ΕΓΚΑΤΑΣΤΑΣΗ
1. Αποσυμπίεσε το ZIP ΜΟΝΟ ΜΕ ΤΙΣ ΑΛΛΑΓΕΣ.
2. Αντέγραψε το περιεχόμενο στη ΡΙΖΑ του υπάρχοντος GitHub repository,
   διατηρώντας τα relative paths assets/ και downloads/.
3. Αντικατάστησε το index.html και ανέβασε τα νέα αρχεία.
4. Κάνε Ctrl+F5 όταν ενημερωθεί το GitHub Pages.

ΣΗΜΕΙΩΣΕΙΣ
- Τα 25 διαγνωστικά περιστατικά είναι ρητά υποθετικά. Δεν αποδίδουν συγκεκριμένες βλάβες σε υπαρκτά μοντέλα.
- Τα σχηματικά διαγράμματα είναι εκπαιδευτικά και όχι OEM τεχνικά δεδομένα.
- Η τελευταία υπάρχουσα έκδοση του τεστ Μαθήματος 7 παραμένει αμετάβλητη.
- Διενεργήθηκαν έλεγχοι σύνταξης JavaScript, 30 σελίδων PDF, ύπαρξης assets,
  περιεχομένου 30 ερωτήσεων θεωρίας και 25x4=100 ερωτήσεων διάγνωσης.
  Δεν διενεργήθηκε live browser end-to-end QA λόγω πολιτικής πρόσβασης του περιβάλλοντος.

- FlexRay: dspace.com (Bus & Networking), ISO 17458 / FlexRay specification
- OPEN Alliance: opensig.org/automotive-ethernet-specifications/
