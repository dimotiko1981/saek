# Εκπαιδευτικό Υλικό ΣΑΕΚ

Ιστοσελίδα εκπαιδευτικού υλικού, οργανωμένη με την εξής σταθερή ιεραρχία:

```text
ΣΑΕΚ
└── Ειδικότητα
    └── Μάθημα
        └── 15 τετράωρα
```

## Τρέχουσα ειδικότητα

- Τεχνικός Μηχανοτρονικής Οχημάτων

## Τρέχον μάθημα

- Δίκτυα και Επικοινωνία Οχημάτων

## Διαθέσιμο τετράωρο

- Τετράωρο 01 — Εισαγωγή στα δίκτυα οχημάτων
- Παρουσίαση θεωρίας σε PDF και PowerPoint
- Φύλλο εργασίας σε PDF και Word
- Αυτοδιορθούμενο τεστ 12 ερωτήσεων

Η δημόσια σελίδα βρίσκεται στο `mathima-01.html`. Ο οδηγός εκπαιδευτή και οι λύσεις δεν περιλαμβάνονται στον δημόσιο ιστότοπο.

## Δημοσίευση στο GitHub Pages

Το `index.html` βρίσκεται στη ρίζα του αποθετηρίου. Στις ρυθμίσεις του GitHub Pages επιλέγεται ως πηγή το branch `main` και ο φάκελος `/ (root)`.
