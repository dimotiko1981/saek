# Εκπαιδευτικό Υλικό ΣΑΕΚ

Ιστοσελίδα εκπαιδευτικού υλικού, οργανωμένη με την εξής σταθερή ιεραρχία:

```text
ΣΑΕΚ
└── Ειδικότητα
    └── Μάθημα
        └── Μαθήματα
```

## Τρέχουσα ειδικότητα

- Τεχνικός Μηχανοτρονικής Οχημάτων

## Τρέχον μάθημα

- Δίκτυα και Επικοινωνία Οχημάτων

## Διαθέσιμο μάθημα

- Μάθημα 1 — Εισαγωγή στα δίκτυα οχημάτων
- Πλήρης μαθησιακή διαδρομή με θεωρία, τεχνικά διαγράμματα, παράδειγμα οχήματος, εργαστήριο, υλικό λήψης και ανακεφαλαίωση
- Αυτοδιορθούμενο τεστ 30 ερωτήσεων, οργανωμένο σε 5 θεματικές ενότητες, με ανατροφοδότηση, πρόοδο απαντήσεων, όριο επιτυχίας 24/30 και τελικό ποσοστό
- Responsive automotive-tech διάταξη με πραγματική φωτογραφία συνεργείου και περιεχόμενο σε οργανωμένες κάρτες

Η δημόσια σελίδα βρίσκεται στο `mathima-01.html`. Η παρουσίαση και το φύλλο εργασίας περιλαμβάνονται στον φάκελο `downloads`. Ο οδηγός εκπαιδευτή και οι λύσεις δεν περιλαμβάνονται στον δημόσιο ιστότοπο.

## Δημοσίευση στο GitHub Pages

Το `index.html` βρίσκεται στη ρίζα του αποθετηρίου. Στις ρυθμίσεις του GitHub Pages επιλέγεται ως πηγή το branch `main` και ο φάκελος `/ (root)`.
